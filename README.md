# curve-sdl-example

This project is a demo example/coding excercise for myself that demonstrates cubic [Bezier curve](https://en.wikipedia.org/wiki/B%C3%A9zier_curve) manipulation with SDL2 and basic graphical rendering and animation (and some keyboard event handling). I made it just because I like math and wanted to get back into C++ programming.

You're free to use, modify or distribute anything from this repo, or ask me anything about the code in commit comments. Cheers.
